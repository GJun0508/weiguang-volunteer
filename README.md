# 微光计划 / 共和小学支教行动

本仓库是 `https://gjun0508.github.io/weiguang-volunteer/` 的 GitHub Pages 静态站。首页以 `index.html`、`styles.css` 和 `script.js` 实现；完整页面文案在 `index.html` 中。

## 改版与信息架构

旧版以「愿景 → 方法 → 特色课程 → 阶段故事 → 图片 → 加入」介绍一般性支教理念。新版沿用旧版的纪实照片首屏、奶油白与深绿配色、衬线标题及长文留白，改为围绕共和小学的具体行动：

1. 首屏：地点、93 人、六个年级和五日行程，以及两个清晰入口。
2. 行动缘起：从具体需要出发，说明“微光”的含义。
3. 认识学校与学生：学校情况、照片出处、93 人明细、图表与可读表格。
4. 课程与周课表：提供全周/星期和年级筛选，默认按屏幕宽度展示整周或单日课程；只显示四至六年级的筹备安排。
5. 行动计划与五日行程：课程、运动、家庭走访、自然研学的准备和反馈方式。
6. 公开进度与结果：状态筛选、带日期的时间线；实践未开展时保留真实空状态。
7. 材料、常见问题与参与支持：原始 PDF、志愿及物资联系入口、捐赠渠道状态、隐私说明；联系方式作为最后一个主要章节。

## 交互与动效

- 图表按钮切换总人数与男女分布；切换不影响旁边的 HTML 表格。
- 周课表支持按星期与四至六年级筛选；桌面端默认显示整周，窄屏默认显示单日。课程可展开查看说明，空白节次明确标注“暂无志愿课程安排”。
- 周五下午另列家庭走访计划，不将走访硬套到某个课时；具体家庭、时段与物资安排待学校协调。
- 行动项目和五日行程使用原生 `<details>` 展开，支持键盘操作。
- 时间线按筹备、确认、进行、完成筛选，没有对应记录时显示空状态。
- 志愿服务、物资支持、正式捐赠咨询三条路径切换后显示相应说明。
- 分享按钮优先使用设备系统分享，不能使用时复制链接，并在状态区域反馈结果。
- 首屏照片与文字只在进入时轻缓呈现；章节分隔、照片、图表和时间线只出现一次。阅读进度条和导航当前章节随滚动更新。系统启用“减少动态效果”时，位移动画停用，内容和反馈保持可见。

## 数据来源与待安排事项

- 学校地点、12 名在职教师、六个年级六个班、日常课时与五日活动框架：用户提供的 `assets/gonghe-school-itinerary.pdf`，用户确认已获校方认可。
- 周课表：团队提供的《教师任课周课表.xlsx》。网页只公开星期、年级、节次、时间及课程名称，不发布教师姓名、工作量或内部排课备注。该表仅列四至六年级，暂作为筹备版，生效日期待学校确认。
- 时间口径待确认：学校情况材料标注上午 8:10、下午 14:00，并记上午四节、下午两节；周课表首节标注 8:40、14:10，且列上午三节、下午三节。网页分别保留两份材料原值，不把周课表视为完整作息表。
- 用户补充周五下午计划走访困难家庭；页面只显示家庭走访计划，不展示家庭身份、地址或困难细节。具体对象与执行安排由学校协调。
- 六年级人数：一年级 14（男 10、女 4），二年级 9（男 5、女 4），三年级 19（男 9、女 10），四年级 15（男 6、女 9），五年级 14（男 5、女 9），六年级 22（男 12、女 10）；用户进一步确认总数为 93 人，男 47 人、女 46 人。原始 PDF 中的 90 人是此前记录，首页已明确说明这一差异。
- 镇域背景：[白盆珠镇简介](https://www.zgcounty.com/wap/news/63241.html)。
- `assets/service-china-proof-2025.pdf` 是过往“服务中国”经历的证明，不作为共和小学本次行动的批准文件。
- 首页和五日行程的背景分别使用用户提供的 `assets/china-reading.jpg`、`assets/china-community.jpg`；学校介绍中的 `assets/original-site/teacher-classroom.jpg` 复制自桌面原站。三张图片均作为氛围配图，不能当作共和小学或本次实践现场。页面已标注；公开使用应确认肖像和传播授权覆盖当前用途。
- 仅最后的联系方式章节使用蓝色天空背景和逐字收尾动画；天空图为 Muhammet Cengiz / Unsplash 氛围图，非共和村实景，见页面内来源与许可链接。其他章节继续沿用原有奶油白、深绿、暖色和照片。
- 具体执行日期、课表最终版本、两份材料时间口径、家庭自愿参与与同意、物资数量和研学地点仍需按实际执行条件安排。行动结果、物资交接和回访不得预填。

## 静态验收

运行 `python3 -m unittest discover -s tests -v` 检查数据、资产、链接和不收款状态。使用任意静态服务器在本目录预览首页，例如 `python3 -m http.server 4177`。所有站内链接与图片路径均使用相对路径，适配 GitHub Pages 的 `/weiguang-volunteer/` 子路径。
